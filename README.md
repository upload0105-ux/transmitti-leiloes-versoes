# Transmitti Leilões — versões

Instaladores do app **Transmitti Leilões** (controle de GCs no vMix para leilões).
Este repositório tem só os instaladores; o código fica em um repositório privado.

- **Baixar:** abra [Releases](../../releases/latest) e baixe `Transmitti-Leiloes-Setup-<versão>.exe`.
- **Atualizar:** o app instalado confere este repositório sozinho, baixa a versão
  nova e avisa na tela ("Atualizar agora"). Os dados do leilão são mantidos.
